# Project 1 / 101 Days Challeges 
## PROJECT NAME: PERSONAL-SOC-HOMELAB

### DESCRIPTION
A lightweight, open-source Security Operations Center (SOC) built to emulate enterprise telemetry pipelines, threat detection engineering, and automated incident response workflow.

### System Architecture
- Attacker: **Kali Linux**
- Defense / SIEM: **Kali Purple**
- Targets : **Windows 7 (Sysmon)** 
- Telemetry Engine: Wazuh / Suricata

### Lab Roadmap (14-Day Sprint)
- Day 1: Define the goal, scope, and success criteria for Personal Security Operations Center (SOC) Home Lab.
Research how similar systems are built in the industry.
- Day 2: Set up the base environment: install the hypervisor/OS images and provision the virtual machines or accounts you'll need.
- Day 3: Study the core theory, architecture, and protocols behind Personal Security Operations Center (SOC) Home Lab so every later step is intentional, not copy-pasted.
- Day 4: Design the system architecture. Sketch a diagram of components, data flow, and how they'll talk to each other
- Day 5: Begin core implementation: install and configure the primary platform/tool.
- Day 6: Continue implementation: bring a second core component online and connect it to the first.
- Day 7: Continue implementation: wire up data flow / integrations between all components built so far.
- Day 8: Checkpoint day: review progress against your Day-1 plan, fix broken pieces, and re-scope if needed.
- Day 9: Add advanced features: custom rules, dashboards, or automation that go beyond the default setup.
- Day 10: Add logging, alerting, or reporting so the system produces visible, reviewable output.
- Day 11:  Functional testing: run realistic scenarios through the system end-to-end and note what breaks.
- Day 12:  Resilience/security testing: stress the system, fix bugs found on Day 11, and tighten configuration.
- Day 13: Write documentation: architecture diagram, setup guide, and lessons-learned notes.
- Day 14: Final review and demo prep: package it as a portfolio piece with screenshots and a short write-up.
